SANDBOX QUIRKS found + documented in skills/web/fuzzing.md:
  * ffuf's scraper reads $HOME/.config/ffuf; the sandbox uid has HOME=/nonexistent, so ffuf ABORTS with
    "open /nonexistent/.config/ffuf/scraper: no such file or directory" before fuzzing. Fix: set
    HOME=/work (+ mkdir -p /work/.config/ffuf) in the experiment.
  * playwright/chromium must be launched with --no-sandbox (--disable-dev-shm-usage) under the
    non-root, cap-dropped sandbox uid.
